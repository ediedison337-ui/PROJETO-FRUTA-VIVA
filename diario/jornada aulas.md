# Aula 3
## Aula 3.1

Hoje aprendi que o HTML é organizado em forma de árvore (DOM).

Pensei nessa estrutura como uma família:

- html e body → ancestrais
- div → pai
- img, h1, p → filhos
- elementos com o mesmo pai → irmãos

A linha vertical do VS Code me ajuda a visualizar essa hierarquia.
# 📅 Jornada - Aula 3

## 📚 O que aprendi

- Entendi a Árvore do Documento (DOM).
- Aprendi a identificar ancestrais, pai, filho e irmãos.
- Descobri como o CSS encontra os elementos do HTML.
- Entendi a diferença entre tag, class e id.
- Aprendi que:
  - tag = nome do elemento.
  - . = class.
  - # = id.
- Entendi que o :hover cria efeitos quando o mouse passa sobre o elemento.
- Aprendi que:
  - transform = o que muda.
  - transition = como essa mudança acontece.
- Descobri que HTML, CSS e JavaScript trabalham juntos, cada um com sua responsabilidade.

# Aula 4 - HTML Semântico e Grid

Hoje aprendi que HTML semântico deixa o código muito mais organizado do que usar apenas divs.

- head e header;
- nav;
- main;
- section;
- footer;

Também entendi o conceito de Grid.

Antes eu imaginava organizar tudo usando margin e pixels.

Agora entendi que o Grid funciona como a planta de uma casa: eu divido os espaços e o navegador organiza os elementos automaticamente.

Consegui relacionar tudo isso com o projeto Fruta Viva e já tenho uma ideia clara de como organizar o HTML antes de começar o CSS.

Também percebi a diferença entre class e id:

- class para estilos reutilizáveis;
- id para elementos únicos, como comparei com um CPF.
