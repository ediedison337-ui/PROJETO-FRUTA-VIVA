# 🟢 Variáveis

| Comando | Significado | Quando usar | Exemplo |
|---------|-------------|-------------|----------|
| let | Variável (pode mudar) | Valores que mudam durante o programa | let idade = 20; |
| const | Constante (não muda) | Valores fixos | const PI = 3.14; |

💡 Pergunta:
"Esse valor vai mudar?"

✅ Sim → let

❌ Não → const

# 🟣 IF

👉 Faz perguntas.

Se a resposta for TRUE executa.

Se for FALSE pula.

Exemplo mental:

É homem?

↓

Sim → mostra masculino.

↓

Não → verifica outra condição.

# 🔵 WHILE

🍈 Palavra-chave:

ENQUANTO.

Quando NÃO sei quantas vezes.

Exemplos:

Enquanto houver gasolina...

↓

Continue dirigindo.

Enquanto existir fruta...

↓

Continue mostrando.

Enquanto o usuário quiser...

↓

Continue ajudando.

---

# 🟣 DO...WHILE

🍈 Diferença do while.

WHILE

Pergunta primeiro.

Depois executa.

DO...WHILE

Executa primeiro.

Depois pergunta.

💡 Executa pelo menos UMA vez.

# 🧠 Método Edson

Quando aparecer uma função nova:

1️⃣ Traduzir o inglês.

2️⃣ Procurar palavras conhecidas.

3️⃣ Associar com HTML/CSS.

4️⃣ Montar a frase.

5️⃣ Só depois decorar a sintaxe.
