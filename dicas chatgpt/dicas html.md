Tag   	 O que faz              	Quando usar                   	Exemplo
<html>	Inicia o documento HTML	/Em toda página HTML            <html lang="pt-BR">
<head>	Configurações da página/Antes do conteúdo da página     <head>
<body>	Conteúdo visível da página/Tudo que o usuário verá	    <body>
<title>	Nome da aba do navegador/Dar um nome para a página      <title>Fruta Viva</title>
<meta>	Informações para o navegador  /	Charset, viewport, SEO. <meta charset="UTF-8">
<link> Liga arquivos externos/Conectar CSS ou favicon	        <link rel="stylesheet" href="style.css">
<script>	Liga JavaScript	/Conectar o arquivo JS            	<script src="script.js"></script>
<h1>	Título principal	Título da página                	<h1>Fruta Viva</h1>
<p>	Parágrafo	Escrever textos                             	<p>Texto...</p>
<a>	Cria um link	Ir para outra página ou site	            <a href="manga.html">Manga</a>
<img>	Exibe uma imagem	Mostrar imagens	                    <img src="manga.png" alt="Manga">
<div>	Caixa de organização	Agrupar elementos	            <div class="menu">
<span>	Estiliza parte do texto	Alterar apenas um trecho	    <span>Viva</span>
<header>	Cabeçalho	Logo e menu	                            <header>
<nav>	Menu de navegação	Links do menu	                    <nav>
<main>	Conteúdo principal	Parte central da página	            <main>
<section>	Seção	Dividir conteúdos	                        <section>
<footer>	Rodapé	Informações finais	                        <footer>
<ul>	Lista sem ordem	Lista com marcadores	                <ul>
<ol>	Lista numerada	Passo a passo                       	<ol>
<li>	Item da lista	Dentro de                               <ul> ou <ol>	<li>Maçã</li>


Vai anotando esses atalhos porque eles economizam muito tempo:

✅ Alt + Z → quebra automática de linha.
✅ Ctrl + / → comenta ou descomenta uma linha.
✅ Alt + Shift + ↓ → duplica a linha.
✅ Alt + ↑ / Alt + ↓ → move uma linha para cima ou para baixo.
✅ Ctrl + D → seleciona a próxima ocorrência da mesma palavra.
