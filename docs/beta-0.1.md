# Fruta Viva - Beta 0.1

## Objetivo
Criar a primeira versão funcional do Fruta Viva.
## Regras visuais do Fruta Viva

- Maraculívia = mascote oficial da abertura
- Laranjinha = mascote da área de joguinhos
- Avatar da criança = personagem neutro e personalizável
- Mascote não é a mesma coisa que avatar jogável
## Telas principais

### 1. Tela de abertura
- Maracum + Lívia
- Mensagem de boas-vindas
- Explicação curta do aplicativo
- Botão "Começar"

### 2. Criação do personagem
- Escolha do corpo
- Cor de pele
- Cabelo
- Roupa
- Chapéu/acessório de fruta

### 3. Tela principal
- Escolha das frutas
- Curiosidades
- Benefícios
- Receitas
- Pesquisa de frutas

### 4. Área da Laranjinha
- Jogos para crianças menores
- Jogo da memória
- Quebra-cabeça simples
- Outros minijogos futuros

### 5. Área Maracum + Lívia
- Quiz
- Mapa-múndi
- Desafios
- Sistema de vidas
